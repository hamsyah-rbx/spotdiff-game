A spot-the-difference game featuring 3 richly detailed vector-drawn scenes (Beach Paradise, Forest Magic, Mountain Peak) with 7 differences each. Click differences in either panel to mark them with animated golden rings. Features include a running timer with par times, a 3-strike system for wrong clicks, up to 3 hints with cooldown that highlight unfound differences, keyboard controls (H for hint, P for pause, R for restart, M for mute), and WebAudio-synthesized sound effects for found items, errors, hints, and scene completion.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
